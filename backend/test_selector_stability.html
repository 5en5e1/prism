🧪 Selector Stability Test Page

Purpose

This page demonstrates the improved selector stability for dynamic content. It shows how different selector types work across page reloads and content changes.

Selector Priority Levels

1. ID Selector HIGH STABILITY
#unique-id

✅ Best for: Static elements with unique IDs

✅ Works across: All page loads

2. Class Selector HIGH STABILITY
aside.sidebar

✅ Best for: Semantic elements with consistent classes

✅ Works across: Most page loads (if classes don't change)

3. Semantic Attributes HIGH STABILITY
nav[role="navigation"]

✅ Best for: Accessibility-focused sites

✅ Works across: All page loads (semantic attributes are stable)

4. Data Attributes MEDIUM STABILITY
div[data-testid="comment-section"]

⚠️ Best for: Test-friendly sites

⚠️ Works across: Depends on implementation

5. Position-based (nth-child) LOW STABILITY
div:nth-child(3)

❌ Best for: Nothing (avoid if possible)

❌ Works across: Breaks with any content changes
